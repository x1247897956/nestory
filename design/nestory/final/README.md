# Nestory icon

Approved design: softened Index silhouette, palette B / Chalk.

- Background: warm paper white, #F3EFE6.
- Foreground: warm graphite, #302E2C.
- Preserve the two panels, central stepped incision and rounded bookmark recess.
- Keep clear space at least equal to the central incision width around the standalone symbol.
- Use the simplified symbol for 16–32px favicons and the padded tile for app icons.

## Files

- nestory-icon.svg — rounded app tile, editable SVG.
- nestory-icon-{64,128,256,512,1024}.png — rounded tile PNGs.
- nestory-icon-square.svg and corresponding PNGs — full square for platforms that apply their own icon mask.
- nestory-symbol.svg — standalone brand symbol in graphite.
- nestory-symbol-black.svg / nestory-symbol-white.svg — monochrome variants.
- favicon.svg / favicon.ico / favicon-{16,32,48}.png — browser assets.
- apple-touch-icon.png — 180px square icon.
- palette.json — exact selected colours.

The icon and browser assets are integrated in web/public. The sidebar uses Nestory and the approved app icon.
The SVG geometry was drawn directly; PNGs were rendered from those SVGs with Sharp.
