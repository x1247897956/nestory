# 仓库结构与提交规则

GitHub 仓库保存可构建的源码、可复现的测试、必要维护工具和当前文档。后端运行镜像只保存 Go API 与运行依赖，独立前端镜像保存 Nginx 和页面产物。普通用户部署无需安装 Python、Node 或测试工具。

## 目录职责

```text
.
├── cmd/noteapp/           Go 程序入口
├── internal/             业务实现及就近放置的 Go 测试
├── migrations/           数据库升级 SQL 与嵌入声明
├── web/
│   ├── Dockerfile        独立前端镜像，Nginx 提供页面与 API 代理
│   ├── src/              前端源码及就近放置的单元测试
│   ├── e2e/              浏览器测试与测试辅助代码
│   └── public/           正式图标等静态资源
├── scripts/
│   ├── operations.py     离线维护入口
│   ├── tests/            维护工具与镜像/Compose 自动化测试
│   ├── audit/            按需性能、故障与升级验证
│   └── media/            演示素材复现工具
├── docs/                 当前使用、开发、架构与协议说明
│   ├── assets/           README 使用的演示截图与视频
│   └── migrations/       仍有用户需要的旧库迁移说明
├── design/nestory/final/  已采用的品牌源文件与图标导出
├── .github/workflows/    自动测试流程
├── .env.example          通用配置模板
└── .local/               按需生成的本机报告，不提交 Git
```

`scripts/prepare-block-migration.mjs` 单独保留旧库离线准备入口。文件用途和依赖见[工具说明](../scripts/README.md)。Go 与前端单元测试留在被测模块旁，避免搬动源码只为按语言分目录。

## 上传与打包范围

| 类别 | 必要性 | GitHub | Docker 运行镜像 |
| --- | --- | --- | --- |
| 应用源码、SQL、锁文件、构建配置 | 构建应用及定位问题 | 保留 | 编译为程序与静态资源 |
| 自动化测试、辅助代码和合成夹具 | 复现行为并防止回归 | 保留 | 不包含 |
| 可复用维护、审计和素材工具 | 离线恢复、专项验证及演示复现 | 保留 | 不包含 |
| 当前文档、README 产品素材、最终品牌资源 | 使用与开发项目 | 保留 | 正式静态资源按构建规则进入 |
| `.env`、数据库、真实附件和 `backups/` | 部署设备的实际状态 | 不提交 | 不打包；数据在运行时挂载 |
| 日志、性能 JSON、原始截图帧、测试报告和缓存 | 可重新生成的执行结果 | 不提交 | 不包含 |
| 旧实施记录、AI 计划、历史验收证据、探索设计草稿 | 已被当前源码、测试和文档替代 | 删除 | 不包含 |
| 纯命令转发 Shell、特定实例配置模板 | 由正式 CLI / 通用模板替代 | 移出公开目录 | 不包含 |

测试源码应与应用一起提交。测试结果由本机保存，或由 [CI](ci.md) 以限时 artifact 保存；README 中精选的演示素材单独保留。

## 清理与忽略规则

不再需要的历史文件与中间归档已删除，仍有用途的旧库迁移说明和性能方法已整理进当前文档。不额外保留一套本机历史副本或逐文件归档清单。

新增本机报告放在 `.local/reports/`。旧的证据、实施/审查记录和探索设计位置也被忽略，避免旧工具重新生成的产物混入后续提交。已有部署只保留自己的 `.env`，不要用示例覆盖。

`.gitignore` 管理后续添加范围；`.dockerignore` 管理 Docker 构建上下文；`.gitattributes` 只影响 GitHub 语言统计等展示，不决定是否上传。已跟踪历史文件会在下一次提交中表现为删除。

本次整理不改写已有 Git 历史。历史提交中的旧内容仍可被检出；是否已存在远端应以实际提交和推送状态为准。

## 依赖信息

当前工具链和依赖以 `go.mod`、`go.sum`、`web/package.json`、`web/package-lock.json` 与 Dockerfile 为准。历史许可证 JSON 含已移除的包且缺少部分当前包，已删除，不再当作当前完整清单发布。项目自身许可见 [LICENSE](../LICENSE)；依赖许可文本与通知应随对应依赖或分发产物保留。
