# 设置与工作空间迁移

从左侧栏底部打开「设置」。本页偏好立即生效，保存在当前浏览器，并同步到同一浏览器中的其他 Nestory 标签页。

## 常用偏好

- **通用**：启动时打开工作台或上次访问的项目列表；直接打开链接时保留链接的目标。
- **外观**：浅色、深色、跟随系统；界面字号与舒适/紧凑布局。
- **日历与时间**：周起始日、12/24 小时制、默认月/周视图、新日程默认时长。各项目已保存的日历视图优先于全局默认；拖选日程保留选定区间。
- **编辑器**：正文字号、标准/宽版正文、浏览器拼写检查。
- **关于**：应用版本、MIT 许可、使用说明和开源仓库。

时区在显式部署时从宿主机系统读取，统一用于日程与日期筛选，见[配置说明](configuration.md)。修改时区影响显示与筛选，已经保存的日程时间点保持不变。

## 日常误删恢复

日常删除的项目、笔记、任务和日程保留在回收站中，按删除批次恢复。没有每日备份、后台快照、自动清空或恢复演练；需要找回误删内容时，从回收站选择对应批次恢复。

## 手动迁移工作空间

换电脑或迁移实例时，由你主动点击「导出工作空间」生成 Nestory ZIP，包含所有项目、笔记、任务、日程、原始块正文、附件、自定义属性、双向关联、最近访问、归档与回收站数据。对象 ID、版本和时间戳保持不变；搜索索引恢复时自动重建。

在线 ZIP 不包含 `.env`、`compose.yaml` 或当前浏览器的偏好。个人设置可以另行导出为 JSON。

手动 ZIP 导出适用于最多 **512 MiB（解压后的数据与附件总量）**、**10,000 个附件**、**64 MiB 结构化记录 JSON** 的工作空间。上传 ZIP 本身也不能超过 512 MiB。超出限制时使用[部署备份脚本](operations.md)，并另存部署配置。

## 导入到空实例

1. 准备一个空 Nestory 工作空间，使用兼容的应用版本。
2. 在「数据与维护」选择 Nestory 导出的 ZIP。
3. 点击「恢复工作空间」，保持页面打开，等待校验与恢复完成。

恢复保留归档内容和回收站。已有内容的实例会拒绝恢复，避免覆盖原有数据；如需切换数据，请在新的部署中恢复。

恢复会检查格式、架构版本、文件 SHA-256、大小、列结构、文档版本、外键和层级关系。写入通过单个数据库事务完成，失败时回滚；附件采用新存储键，对象 URL 保持不变。目前在线 ZIP 格式版本为 1、数据库架构为 10；它与离线部署备份的 tar 格式不同。

## 个人设置与重置

「导出设置」只包含本设置页的偏好；「导入设置」校验后立即应用，不导入笔记或附件。

「恢复默认偏好」会重置本页选项、各项目的列表/看板视图、日历视图、排序、折叠与筛选，并通知其他打开的标签页。笔记、任务、日程、附件、未保存草稿和待确认的创建请求都会保留。

浏览器拒绝存储时，偏好仍可临时使用，设置页会显示保存失败提示，并提供重试入口。清除浏览器站点数据会清除偏好和浏览器草稿；日常重置请使用应用内的「恢复默认偏好」。
