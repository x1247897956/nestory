# 工作台日历创建日程修复

根因是工作台 FullCalendar 没有 interactionPlugin、dateClick/select 回调。补上日期点击与时段框选：月视图默认当天 09:00–10:00，周视图单击使用半小时槽位，拖动使用实际框选区间，按应用时区输入和保存。

跨项目工作台在弹窗中明确选择活跃项目、标题、开始/结束；选择项目并输入有效标题/时间后自动保存，留在工作台并刷新日历，提供查看日程入口。归档项目不显示，服务端业务规则仍兜底。项目加载/无项目/非法时间/保存失败/未保存关闭均有状态。

复用既有 API 创建意图幂等键；未知结果失败时锁定原输入并重试同一意图，避免修改后误建第二条；确定性 4xx 允许修改，保留输入。保存中禁用关闭/编辑，取消清理未完成意图并刷新日历以确认可能已保存的结果。不改数据库、依赖、项目内日历写入路径。
