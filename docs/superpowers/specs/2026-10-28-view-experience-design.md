# 视图、时间轴、排序与详情一致性

用户已指定本轮完成：视图设置记忆、日程甘特图、对象详情一致、排序。沿用前面确定的方案：甘特式时间轴属于日程，以现有开始/结束时间显示横条；任务仍为列表/看板。

- 偏好按项目和对象类型保存在当前浏览器；任务列表/看板、阶段分组/折叠、排序；日程日历/时间轴、周/月跨度和查看日期；笔记排序。保留原有任务视图和筛选偏好，损坏或不可用存储不阻断操作。偏好不修改业务数据。
- 排序：任务默认顺序、标题、优先级、截止日期、创建/更新时间；笔记默认顺序、标题、创建/更新时间；时间轴按开始/结束、标题、时长。提供升降序、空值始终最后、稳定 ID 兜底，父子结构保持。
- 时间轴：左侧日程标题，右侧按应用时区的周/月区间显示横条；上/下区间、今天、缩放，长日程裁剪而不改数据；端点按半开区间；支持点击详情、相同新建入口，加载/空/错误/归档只读明确。首版不做依赖连线、自动排程或时间轴拖拽改日期（现有日历拖拽保留）。
- 三种对象详情共用标题/菜单/属性的结构与样式，正文和保存/恢复提示位置一致；保留自动保存、未保存保护、恢复和只读约束，不改文档格式。

实现不引入第三方依赖或数据库迁移，继续使用 React、Luxon 与当前日历；排序和偏好纯前端，日程继续使用现有范围查询 API。界面延续黑白和深蓝点缀。阶段折叠纳入任务显示设置，支持全部展开/收起和拖入折叠阶段。
