# 对象列表布局与排序器统一

用户指出任务/笔记/日程列表页布局不一致，以及排序应像筛选一样是排序器。按现有黑白/深蓝风格直接修正。

三页共用 CollectionHeader：标题与数量/状态、新建操作在首行；视图与工具在第二行；筛选/排序条件区在工具附近；内容区留相同间距。三页外部 padding、标题字号、工具控件高度一致，日历/看板/列表自身结构保留。日程排序只在时间轴中可用（日历位置由时间决定），不可暗示排序会改变日历格子。

排序为单规则条件编辑器，按钮打开锚定弹层，属性/方向仅作为草稿，点击应用生效。已生效非默认规则以可编辑标签展示，可清除恢复默认顺序。现有 SortSpec 与偏好存储保持兼容；暂不新增多级排序，不改业务 API、数据或依赖。弹层支持 Escape/外部点击取消、键盘与小屏约束。
