# 任务筛选器

依据用户已确认的筛选器模式实施：工具栏筛选按钮打开属性选择，已生效条件显示为可编辑/可移除标签，所有条件 AND 组合。任务列表、看板共用条件；项目之间隔离并持久化本机偏好。

支持标题文本、阶段、优先级、截止日期，以及同项目任务的文本/网址/单选/多选自定义属性。文本包含/不包含/为空/不为空，单选是/不是/为空/不为空，多选包含任意/包含全部/不包含及空值判断，日期早于/晚于/区间/今天/本周和空值判断。日期按应用时区，周一至周日，日期区间端点包含；“早于/晚于”采用严格比较。空值与未设置优先级区别明确。

不完整条件不生效，点击应用才添加/替换；无匹配结果显示清除入口。父任务不匹配而子任务匹配时仍保留上下文，但父任务不计入匹配数；看板只显示匹配对象。删除属性或选项后，将失效条件标出并暂停匹配（不能悄悄展示全部或隐藏全部），允许移除/重选。属性读取失败时显示重试，不能按空值误判。

实现选择：沿用当前完整任务列表接口，在前端以可测试的纯函数计算条件；新增项目/类型作用域批量自定义属性快照接口，避免 N+1。相比服务器动态过滤，不引入查询语言和重复的业务规则；不改正文接口、数据结构或依赖。筛选偏好本地存储，存储不可用时保留当前会话操作。暂不做 OR/嵌套、保存命名视图、笔记/日程筛选及时间轴。
