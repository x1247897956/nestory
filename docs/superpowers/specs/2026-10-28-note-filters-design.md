# 笔记筛选

笔记列表复用已验证的任务筛选器交互和运算：标题、创建/更新时间，以及项目内笔记的四类自定义属性。多个条件 AND，编辑后应用，标签修改/移除，空结果提供清除入口。按项目与对象类型隔离偏好，任务原有条件和存储键保持兼容。

创建/更新时间从 Unix 毫秒转换为应用时区的日期，所有涉及这些时间戳的条件（包括绝对日期）必须等待时区配置；相对日期沿用午夜/重新进入/聚焦刷新。自定义属性复用现有 pages 批量快照接口和 object 缓存失效机制，不加 Go API 或 schema。属性/选项删除和请求失败明确提示，不把失败当空值。与排序组合，详情关闭保持筛选，归档可筛选但不编辑。
