# Task Filters Implementation Plan

**Goal:** 已确认的 Notion 风格任务筛选器，列表/看板共用，项目隔离。
**Architecture:** 纯函数过滤任务和属性快照，React 弹层编辑条件，本机偏好持久化；Go 事务内批量读取属性定义和值。
**Tech Stack:** 现有 Go/SQLite、React/TypeScript/React Query，不加依赖。
**Spec:** docs/superpowers/specs/2026-10-27-task-filter-design.md

## Global Constraints
- 保留品牌等现有未提交工作；不改任务正文接口，不修改数据库结构。
- 黑白与深蓝色，键盘可操作，小屏不溢出，加载/失败/空结果状态明确。

## Review Focus
- 属性/选项删除、加载失败不能造成错误匹配。
- 空日期、空文本、多选包含全部、AND 组合必须正确。
- 不同时区的今天/本周边界正确。
- 切换项目/视图及存储损坏不能泄漏条件。
- 过滤后父子上下文与拖动保存行为不倒退。
