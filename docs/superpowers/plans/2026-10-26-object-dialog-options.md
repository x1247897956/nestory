# 居中对象详情与属性/选项职责

用户已确认：只精简本地空间文案，不删除任何现有项目或对象数据。

## 交互与合同

- 对象详情采用应用内居中浮层（参考图），URL继续可直达和刷新；底层是对应类型列表，顶部为项目名/类型/对象名，逐级可点。关闭、Escape和导航保留草稿/文件处理保护。
- 移除返回链接、重复外层标题、重复工作空间/本地私有等文案。浮层内部保留用于改名的对象标题输入。
- 固定属性使用真实SVG图标；统一名称和内容列起点，包括关联、阶段。
- 属性设置只改名并提供自定义属性删除，不展示类型共享描述或选项管理。
- 选项在选择面板的悬停/键盘焦点三点入口单独管理名称、颜色、删除；触屏入口始终可见。
- DELETE /api/v1/property-definitions/{id}，body {version}，事务内删除全部自定义值及定义；仅自定义定义可匹配，默认属性不可删除；归档只读。UI明确确认影响同项目当前类型所有对象、包括回收站中的值，且不可撤销。
- DELETE /api/v1/property-definitions/{id}/options/{optionId}，body {version}，事务内移除选项，并清理引用它的单选/多选值（空值为null），仅受影响值的独立version递增；原生对象/正文version不变；归档和定义CAS保护；PATCH仍禁止偷偷删选项。
- 删除响应丢失时前端重新读取确认，不重复破坏数据；失败保留输入。所有测试使用临时SQLite/独立Docker，真实运行数据不用于破坏性验收。
