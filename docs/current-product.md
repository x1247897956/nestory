# Nestory 当前产品与文档入口

更新：2026-10-29。本文描述当前实现；原始设计、阶段计划、审查及验收日志保留当时的事实，不能将旧界面和旧存储格式当作当前使用说明。

## 当前行为

| 范围 | 现行行为 |
| --- | --- |
| 项目 | 聚合任务、笔记、日程；汇总页提供三类内容入口和创建操作。侧栏项目菜单提供重命名、归档/取消归档、置顶/取消置顶、删除。 |
| 笔记 | 笔记列表为扁平界面，不提供子笔记创建、目录树或父级/顺序属性编辑。旧库层级数据及后端同项目/防循环约束保留，不自动删除或扁平化已有数据。 |
| 正文 | 三类对象统一使用 BlockNote 块编辑器，输入 `/` 插入内容，没有源码/预览/分屏切换。服务端只保存版本化 `body_document` JSON；Markdown仅用于导入/导出，不是第二套正文。 |
| 详情 | 应用内居中浮层，顶部项目 / 类型 / 对象名。统一标题、对象菜单、默认折叠的两列属性、正文和保存状态；小屏属性变为一列。 |
| 任务 | 五个固定阶段、一层子任务、父子状态独立；列表/看板，阶段拖动、阶段折叠、筛选器、排序器。 |
| 日程 | 开始/结束时间、日历周/月和按时间跨度展示的时间轴。时间轴不支持依赖连线、自动排程或拖动改期；日历保留拖动改期。不是完整项目排程系统。 |
| 工作台 | 跨项目日历和未完成任务列表。日历可点击日期或框选时段，选择活跃项目及填写标题后自动保存；日程始终属于项目。 |
| 属性 | 固有属性和关联统一在属性栏。自定义文本、网址、单选、多选定义按项目及对象类型共用，同类型对象自动获得定义，值独立。跨类型复用是复制定义与选项/颜色，不是持续联动的全局字段。 |
| 属性操作 | 属性设置管理名称和删除（固有属性不可删）；选项行悬停三点菜单管理选项改名、颜色与删除。网址可直接打开。 |
| 筛选/排序 | 任务与笔记支持固有/自定义属性筛选，多个条件为AND。排序通过排序器应用；视图、分组、折叠、筛选和排序偏好只在当前浏览器按项目/类型记忆。 |
| 保存与恢复 | 已有对象自动保存，失败保留草稿及重试入口，未保存离开有提示；创建使用幂等请求避免丢失响应后重复创建。归档只读，删除按批次恢复。 |
