# 统一对象属性栏与折叠关联

## 实现
- 任务、笔记和日程共用 ObjectProperties，统一标题下的属性栏与编辑样式。任务保留阶段、优先级、截止日期与父任务；笔记父级及移动控件收进顶部属性；日程起止时间在顶部原位编辑，保留部署时区解释。
- 关联作为属性，默认收起为“关联 + 数量”。展开浮层展示关联对象与同项目搜索、添加和移除操作，不再渲染正文底部的大面板。
- 支持键盘打开、Escape关闭并返回焦点、点击外部关闭；面板在390px屏幕内显示。提供加载、空数据、错误重试、请求处理中禁用和归档只读状态。
- 删除操作从关联中分离为顶部对象操作，保留预览确认、草稿保护和按批次恢复规则。
- 复用既有双向关联API，没有修改数据模型或引入自定义属性。

## 实际验证
- 前端类型检查与生产构建通过，单元测试20项通过。编辑器单测补充了属性栏所需的路由及查询上下文，原有冲突与在途保存断言保持不变。
- 新增浏览器用例覆盖三类对象默认收起、展开查看、键盘/外部关闭、手机边界、移除后的反向同步与归档只读。
- 完整18项浏览器运行中17项通过，另1项因跨对象导航后未等待新编辑器加载而操作了旧折叠面板失败。修正测试等待条件后，两个浏览器时区的关联专项2项均通过（14秒）。此前折叠后仍直接断言可见的旧用例也已更新为先展开。
- 桌面1440px和手机390px展开/收起截图检查通过。
- Docker构建通过，18084沿用原数据卷重建成功，部署smoke七项通过。
- 已有约1.67MB主包提示仍在；不新增依赖。仅本地提交，不推送。
