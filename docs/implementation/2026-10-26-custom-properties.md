# 自定义属性实现与验收（2026-10-26）

已完成用户确认的范围：先选文本/单选/多选/网址，再命名，最后填写当前对象的值。定义自动出现在同项目同类型的所有已有/新建对象上，值各自独立；名称、候选项共享，选项使用稳定ID。任务、笔记、日程使用同一属性栏实现。

[设计](../superpowers/specs/2026-10-26-custom-properties-design.md)、[已完成计划](../superpowers/plans/2026-10-26-custom-properties.md)、[API](../custom-properties-api.md)、[全部执行记录与截图](../evidence/custom-properties-20261026)。

## 实现

- Go `internal/customproperty` 独立服务，普通构造函数组装；`object.CustomDefinition/CustomProperty` 为纯对象视图模型，通用对象API也聚合属性。未增加依赖或通用工作流/属性引擎。
- schema9只新增定义和值两表，复合外键约束项目、类型及原生task/page/event引用；定义稀疏共享，不改写旧对象或正文。
- 定义和值独立版本；值保存不增加正文版本，避免互相覆盖。写事务同时校验对象有效、项目可写、定义范围、值类型和版本。创建复用持久幂等请求。
- 定义/选项/值自动保存；复用本机草稿、冲突保留、复制/重试/显式重新载入、强制关页恢复。属性设置首次打开时才挂载，防止另一篇笔记的隐藏设置草稿阻塞值保存或导航；仅定义版本变更且值版本未变时，刷新定义并进行一次同值CAS重试，不覆盖其他对象/窗口已提交的值。
- 单选、多选选项支持新增/重命名，既有选项ID不变；多选清空及网址空白规范化，避免成功写入丢响应后误报冲突。HTTP(S)之外或内嵌凭据网址被拒绝。
- 删除指纹包含适用定义与值版本，空项目也包含其所有定义版本；预览后的字段修改要求再次确认。软删除保留值，批次恢复重新可见；归档只读。

## 失败、独立复核与修正

- 原接口尚不存在的API回归先红灯；实现后通过。首次前端单测因测试壳未提供新属性查询夹具而3项失败，补充空属性夹具后完整通过。
- 一个名字控制字符测试把会被trim的外侧换行当成非法存储值，改成真正的内嵌控制字符后验证拒绝；未把测试期望错误当成数据故障。
- 空项目增加定义后旧删除预览初次仍被接受，已红灯复现并补定义版本指纹。
- 独立只读复核发现P2：始终挂载的共享定义草稿hook可能从另一标签接收冲突，从而使隐藏设置永久阻塞值保存/导航。旧镜像新增跨页用例先复现失败，修复为设置懒挂载、值保存独立与定义版本安全刷新；两个跨页回归和最终全量通过。复核未发现其他已确认P1/P2；同时修复100选项时Enter越界和空多选/网址空白规范化两项P3。
- 实际备份副本演练首次已验证升级不改旧表，之后因停启临时容器的动态宿主端口重新分配，脚本继续使用旧地址而连接拒绝。演练脚本改为备份后重新发现端口，再次完整通过；正式实例固定18084，不受该脚本问题影响。

## 部署、数据保护与回滚

最终镜像 `noteapp:custom-properties-20261026`，ID `sha256:4365f2448a952cf75f8b06c76dd08befe0377dd054125bf505eeb0e5bff3c994`。正式 `noteapp-v1-check-noteapp-1` 使用原 `noteapp-v1-check` 卷，经Compose `--no-build --force-recreate --wait` 更新，继续绑定127.0.0.1:18084，时区/Host白名单/上传限制不变。

实际部署前后全卷备份：`backups/2026-10-26-before-custom-properties`、`backups/2026-10-26-after-custom-properties`，均为Git忽略的私有本地备份。提取副本按SQL原生值（含BLOB）比较原12表所有行/列，除新增迁移9外完全相同；12附件SHA不变，新属性两表为0行，没有向正式项目注入演练字段。备份后实例恢复运行，真实笔记属性API读取返回空fields和read_only=false。

可复现脚本为 `scripts/audit/custom_properties_rehearsal.py`（参数见 `scripts/audit/README.md`），交付脚本再次运行通过。早先实际副本升级/恢复演练备份为 `backups/2026-10-26-custom-upgrade-9e689f5a3a` 和 `backups/2026-10-26-custom-values-9e689f5a3a`，均保留且不入Git。回滚镜像 `noteapp:object-menu-20261026` 保留。schema降级不自动支持；需要把部署前备份恢复到预建空卷，并使用备份清单的旧镜像。不要直接将旧镜像指向已升级且存在新属性的卷。

## 已知边界

本轮不提供属性类型转换、删除定义/候选项、按属性筛选/搜索或自定义排序。每项目每类型64定义、100选项，名称80、文本4000、网址2048字符。属性设置草稿会在再次打开该字段设置时恢复；本机未提交草稿不属于服务器备份。既有个人/可信LAN使用范围、列表完整正文容量、辅助技术和大包优化限制仍保留，不将本次功能回归称为全面渗透审计。
