# 项目菜单与紧凑对象详情

## 用户批注落实
- 每个项目右侧新增独立“⋯”菜单：重命名、归档/取消归档、删除、置顶（Pin）/取消置顶。弹层使用浏览器popover顶层，不被侧栏滚动区域裁切；长删除预览可滚动并居中确认。
- 属性栏取消“属性”标题、边框背景和大块留白，标签与值同排，窄屏自然换行。关联保持默认折叠。
- 移除“Markdown正文”可见标题，保留无障碍输入名称。默认使用CodeMirror即时模式，在同一编辑区装饰Markdown，保留文本源、IME及既有自动保存机制。支持标题、强调、引用、代码、链接、图片和检查项；代码围栏内的伪检查项不会变成按钮。源码、预览、分屏继续可用；复杂GFM表格依然可在预览/分屏中完整展示。
- 面包屑为工作空间/项目名/对象名，项目概览无“概览”后缀，笔记与日程显示真实对象名。
- 笔记目录和新建表单仅在列表页出现；详情不展示父笔记或内部排序字段。已有层级业务保留在后端。
- 日程详情不再挤在日历右侧，独立完整内容页，属性位于标题下，返回按钮回到日历。
- 上传按钮改为紧凑“附件”，保留真实上传与错误展示。
