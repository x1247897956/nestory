# 阶段 4 实施报告

范围：今日工作台、全局搜索、最近访问、按批次回收站与归档只读。未实施阶段 5。

## 实现

- `internal/workspace` 使用构造函数注入 `Clock`，由部署时区求当天零点及下一日历日零点；今日/逾期任务按自身日期和阶段筛选，保留已完成父任务下的未完成子任务；Event 按半开区间交集筛选。工作台展示项目、父任务与部署时区的日程时间。
- 搜索覆盖项目说明及 Task/Page/Event 标题与正文，参数化 LIKE 转义反斜杠、百分号与下划线；中文子串、空查询、稳定排序、limit/offset 分页、Page 完整路径和显式包含归档。界面显示对象类型及所属项目。
- 打开项目/Page 记录最近访问，默认排除已删除和归档对象；允许记录只读项目访问。
- 迁移 004 增加 `delete_batches`、`recent_visits`。三类对象删除预览返回 version、count 和实际成员清单；DELETE 在同一事务重新检查项目可写、根版本与当前数量，不一致返回 409，界面更新预览并要求再次点击确认。
- 删除仅标记当前存活根/后代，保留先前删除的后代批次及所有关系。回收站可展开查看批次成员；恢复仅清除此批标记。仍删除的祖先返回冲突和所需批次；归档项目恢复被拒绝，界面同步禁用恢复按钮并解释原因。
- 恢复事务额外重验 Task 一层子任务约束：先删子任务 C，再把父任务 A 移到 B 下，恢复 C 会拒绝，要求先把 A 移回顶层。
- 删除入口复用三类对象的关联区；未保存草稿或在途保存时拒绝打开/执行删除，保留现有草稿队列和时间保护；软删关联显示已有“已删除”占位，恢复后恢复可点击关系。
- 复核 Task/Page 创建、编辑、移动，Event 创建/编辑，Markdown 检查项、关系、附件上传、删除和恢复的归档边界：服务在事务内拒绝，界面使用原有只读控件和新的删除/恢复保护。
