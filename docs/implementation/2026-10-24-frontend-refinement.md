# 前端导航与工作台调整

## 实现
- 黑白与中性灰为主，深蓝点缀；紧凑侧栏、轻量分隔线与清晰的内容层级。
- 项目默认进入汇总，通过汇总打开任务、笔记、日程；取消项目下拉导航与重复栏目导航。
- 添加任务操作置于任务区右上角；用户界面将“页面”统一为“笔记”。
- 侧栏移除活跃项目、归档项目的直接入口，归档列表保留在项目选项菜单中，支持手机端。
- 今日工作台不显示时区，不放置创建项目按钮；优先处理区域突出逾期与今日任务，日程和最近访问为辅助区域。
- 日期计算仍遵循服务配置时区，未改变业务规则。各区域连接真实 API，保留加载、错误、空数据与草稿保护。
