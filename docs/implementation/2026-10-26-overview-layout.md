# 项目汇总与属性排版

- 项目汇总只在顶部显示一次项目名称，说明保留；列表页使用各自已有的内容标题，移除重复项目头部；项目操作统一留在左侧三点菜单。
- 移除汇总的“项待推进”，数量保留在各内容栏。
- 三个新增入口统一为 36px 深蓝按钮，查看全部采用次级文字入口。
- 固定属性和自定义属性使用相同的名称/值列，桌面与手机按行对齐。
- 移除新建子笔记入口，所有已有笔记平铺展示，创建一律为顶层笔记。
- 历史父子数据、删除批次及后端兼容接口保留，避免改变旧记录恢复语义；不做破坏性数据迁移。

验收：构建、单元测试、独立容器浏览器回归、1261/773/390px 截图；部署前后备份与逐行核对。

实施检查发现：将项目名合并到导航后，内层“汇总”链接的可访问名称影响了标题名称。已为标题保留真实项目名，链接继续使用“汇总”导航名称，随后重新执行完整浏览器回归。首次中止日志保留供追溯。

笔记后端父子约束、删除批次及恢复测试不作删减；仅产品界面取消层级，新创建请求固定 `parent_id:null`。历史子笔记按普通笔记在列表显示，正文与原始数据不改写。

视觉检查：1261px、773px、390px 实际浏览器截图；移除任务属性区域重复的底部分隔线，固定属性下拉控件改为随内容收紧，避免整行拉伸。

此次无需数据库迁移，依赖锁定文件不变。首次最终构建曾因审批服务额度不足未执行；用户继续后审批恢复，已重新执行构建。该失败并非安全策略拒绝。
