# 后端架构优化实际记录

## 完成内容
1. 提取objectquery应用服务，将对象读取、归档状态与关联组合移出HTTP handler；普通构造函数装配读取能力。
2. 新增apperr，业务模块不再依赖httpx；保留HTTP错误格式与兼容错误身份。附件HTTP方法单独移入asset/http.go。
3. 新增taskmeta集中任务默认值、阶段、优先级及终结状态。创建、校验、config、对象属性选项和工作台筛选复用定义。数据库约束保留并通过一致性测试校验。
4. 缩短附件事务：客户端流接收完成后才占用数据库连接，事务内再次检查归档状态，失败清理文件和元数据。
5. 明确统一读取模型与修改语义：对象版本不包含独立关系增删，不承诺组合读取具备跨记录事务快照。未引入通用属性存储或复杂DI。
